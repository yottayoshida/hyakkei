# 5分導線の実機確認（#16）

目的は、非技術者が「取り込み → 集計 → グラフ化 → 保存/配布」を5分以内に完了でき、サンプル表示を実データと誤認しないことを確認することです。

1. `pnpm run build` 後に `packages/app/dist` をローカル配信し、Chrome/Firefox/Safari のいずれかで開く。
2. CSV または XLSX を「データを追加」へドロップする。
3. 「集計を追加」で列を選び、必要なら条件を1つ設定する。
4. 「グラフ化」→「並び順を編集」→幅/高さボタンを1回ずつ操作する。
5. ダッシュボード名を入力し、「保存」と「配布用HTML」を実行する。
6. 保存した JSON を「開く」で読み込み、元データ未接続の警告と再接続導線を確認する。

補足: 「配布用HTML」は単一ファイルなので `file://` で開ける。フォルダ形式（`index.html` + `renderer.js` + `dashboard.json`）は `dashboard.json` を相対取得するため、静的HTTPサーバーで確認する。
