# ギャラリー公開データ

ギャラリーの3サンプルは、実行時に外部サイトから取得しません。e-Stat の公式表を取得時点で固定し、必要な列・地域だけを UTF-8 CSV に正規化して同梱しています。各 **normalized snapshot CSV** の SHA-256、表番号、公開日時、取得日、調査年、変換規則、値の照合結果は `packages/core/src/gallery-samples/data/provenance.json` に記録しています。これは画面表示から抽出した同梱データのハッシュであり、e-Statの未加工配布ファイルそのもののハッシュではありません。

| サンプル | e-Stat 表 | 調査年 | 用途 | 同梱スナップショット |
| --- | --- | --- | --- | --- |
| population | [0000010201 Ａ 人口・世帯](https://www.e-stat.go.jp/dbview?sid=0000010201) | 1975年度 | 都道府県別の総人口と男女別内訳 | `population.csv` |
| economy | [0000010203 Ｃ 経済基盤](https://www.e-stat.go.jp/dbview?sid=0000010203) | 1975年度 | 産業構成・耕地面積比率・土地生産性 | `economy.csv` |
| administration | [0000010204 Ｄ 行政基盤](https://www.e-stat.go.jp/dbview?sid=0000010204) | 1975年度 | 財政指標・人口1人当たり歳出 | `administration.csv` |

画面表示値の単位・指標コードを CSV ヘッダーへ残し、桁区切りを除いて数値として扱える形にしています。未取得の値を補間したり、ランキング用に並べ替えたりしていません。ダッシュボードの `sources[].ref` は同梱ファイル名に加えて表番号・URL・調査年を持ち、アプリの実行時ネットワーク要求は発生しません。

## 調査年を必ず記録する

3表とも同じ URL で50年分の調査年を配信しています。**表番号だけでは、どの年の値かを読者が確認できません。** 当初 `economy` と `administration` は `surveyYear: "画面表示値"` のまま公開されていました。2026-08-10 に3ページを実ブラウザで開いて確認したところ、いずれも期間選択の既定値が1975年度であり、`population` と `administration` については同梱CSVの各行が表の値と一致しました（`economy` はデータ表が描画されず行単位の照合ができていません。この差は `provenance.json` にそのまま記録しています）。

CSV を差し替えるときは、公式表の公開日時と**調査年**を確認して `provenance.json` の取得日・調査年・ハッシュ・変換内容・照合結果を同じ変更で更新してください。`pnpm --filter @hyakkei/core test` の provenance テストが、記録されたハッシュと実ファイルの不一致、調査年のプレースホルダー、`meta.sourceNote` への表番号・調査年の欠落を検出します。

## 表示できる桁を落とさない

e-Stat は指標ごとに決まった小数桁で公表しています（耕地面積比率 `15.0` と `13.7`、財政力指数 `0.500` と `0.448`）。JSON の数値は末尾のゼロを保持できないため、これらを数値として持つと同じ列に `15` と `13.7` が並び、値の精度を偽って伝えることになります。**表に出す小数はすべて公表どおりの文字列で持ちます。** 整数（総人口の万人単位など）は数値のままです。`gallery-samples.roundtrip.test.ts` が列ごとの小数桁の一致を検査します。

## 掲載地域の選び方

`population` は全国・東京都・神奈川県・大阪府・沖縄県、`economy` と `administration` は全国と表示順の先頭4道県です。**選び方が2種類あるのは取得時の経緯によるもので、統計上の基準ではありません。** 棒グラフには全国を含めていません（合計と内訳を同じ軸に並べると、全国の桁が他をつぶすため）。全国の値は表と要約に出しています。

## 使えるチャート型

公開サンプルは `bar` / `stat` / `table` だけを使います。`line` と `area` は順序のある軸を必要としますが、同梱しているのは単一調査年の地域横断データなので、都道府県をx軸に置くと存在しない推移を描くことになります。`pie` は同一単位の内訳を必要とします。`scatter` は encoding が x/y/size のみでラベルの経路がなく、5地域では読者がどの点がどの地域か判別できません。理由は `gallery-samples.roundtrip.test.ts` の `PUBLISHABLE_CHART_TYPES` に併記しています。複数年のスナップショットを追加すれば `line` / `area` を正しく使えます（別途対応）。
