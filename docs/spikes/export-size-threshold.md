# 配布用HTMLのサイズしきい値測定

測定日: 2026-08-09
対象: `planDashboardExport()` が生成した実ファイルの UTF-8 バイト数

`String.length` は日本語を含む場合の通信・保存サイズを表さないため、判定は常に
`new TextEncoder().encode(html).byteLength` を用いる。単一HTMLの案内しきい値は
20 MiB（20 × 1024 × 1024 bytes）で、超過時も強制的に形式を切り替えない。

## 再現条件

1グラフ、`category: "項目${index}"` と `value: index` の行を 10,000 / 50,000 /
100,000 件生成し、table / scatter それぞれで測定した。レンダラーはこのリポジトリの
生成済み IIFE を含む。

| グラフ | 行数 | UTF-8 bytes | MiB |
| --- | ---: | ---: | ---: |
| table | 10,000 | 1,679,128 | 1.60 |
| table | 50,000 | 3,319,128 | 3.17 |
| table | 100,000 | 5,369,128 | 5.12 |
| scatter | 10,000 | 1,679,126 | 1.60 |
| scatter | 50,000 | 3,319,126 | 3.17 |
| scatter | 100,000 | 5,369,126 | 5.12 |

この合成データでは100,000件でも20 MiB未満だが、実データの長い文字列・複数グラフでは
超える。したがって行数から推測せず、書き出し直前に完成HTMLを測定する。

## 利用者に見せる選択肢

20 MiBを超えたときは次の3択を必ず表示する。

- 単一HTMLで書き出す
- 固定3ファイル（`index.html`、`renderer.js`、`dashboard.json`）のフォルダーZIPで書き出す
- キャンセル
