# テンプレート作成ガイド

Hyakkei のテンプレートは `dashboard.json` です。元データそのものではなく、データソースの名前、列名、集計条件、グラフ、レイアウトを保存するため、同じ列構成の定型レポートを繰り返し作れます。

## 作る

1. 個人情報を含まない代表データで、CSV または `.xlsx` を読み込みます。
2. 「このデータを集計」で、用途に必要な単位・値・条件を設定します。
3. 「グラフ化」で見せ方を選び、タイトルとレイアウトを調整します。
4. 「保存」を選び、`dashboard.json` を分かる名前で保管します。

## 使う

1. ヘッダーの「開く」からテンプレートの `dashboard.json` を選びます。
2. 求められたときは、テンプレート作成時と同じ列構成の元データを選びます。
3. プレビューで集計値と見出しを確認し、必要ならタイトル・条件・レイアウトを更新します。
4. 作業用には「保存」、配布用には「配布用HTML」を選びます。

## 公開前の確認

- `dashboard.json` にはセル値を保存しませんが、元データのファイル名・シート名・列名・SQL の集計条件を保存します。機密情報が名前に含まれないようにします。
- 配布用 HTML には、表示するグラフを再現するための集計済みの行が入ります。データの公開可否と共有先を確認します。
- テンプレートの列名を変える場合は、クエリとグラフの列指定も更新してから保存し直します。

## Git で管理する場合

`dashboard.json` はレビュー可能なテキストです。テンプレートとその代表データの説明を同じ変更に含め、変更後は実際に開いてグラフと値を確認します。ブラウザで完結するため、静的ホスティング（GitHub Pages、オブジェクトストレージ、通常のファイルサーバー）でも配布できます。
